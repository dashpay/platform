# Identity discovery vectors

Deterministic, signed protobuf responses generated by
`rs-drive-abci/tests/identity_discovery.rs::should_export_nonunique_sdk_fixtures`:

```sh
DASH_SDK_EXPORT_NONUNIQUE_VECTORS=1 cargo test -p drive-abci --test identity_discovery should_export_nonunique_sdk_fixtures -- --ignored
```

`pvN-v{0,1}-{0,1,2}.bin` answer the request version `v0` or `v1` for the first
match, the next match, and exhaustion. A V0 answer carries separate index and
identity proofs (result field 2), produced by the two-proof producer at protocols
12, 13 and 14; every protocol version serves V0. A V1 answer carries one proof of
both (result field 2 of response V1), produced at protocol 14, the first version
that serves V1. The generator verifies every answer before writing it.
`newer-v{0,1}-0.bin` are first matches built with the protocol 14 rules and signed
as protocol version 1000, far above any real version, so the SDK always reads them
with the newest rules it knows. They keep verifying as long as those rules build
the same non-unique lookup query as protocol 14.
The fixed test signing key is `[1; 32]`; `quorum-key.bin` is its public key.
`key-hash.bin` is the requested index key. These are synthetic fixtures, never
network trust anchors. The SDK tests replay these through the normal proof and
signature verifier.

`mainnet/` holds real V0 answers from mainnet protocol 13 nodes, recorded at
height 456535 by
`rs-sdk/tests/identity_discovery_live.rs::should_capture_mainnet_v0_nonunique_vectors`
(`DASH_SDK_CAPTURE_MAINNET_VECTORS=1 cargo test -p dash-sdk --test identity_discovery_live capture -- --ignored`):
`match-*` is a first match (`match-identity.bin` is the identity found) and
`absence-*` proves no identity after `[0xff; 32]`. Each `*-quorum-key.bin` is the
public key of the quorum that signed that answer, read from the trusted quorum
service at capture time. Responses are stored as the SDK re-encodes the decoded
message; the proofs inside are opaque byte fields and are kept verbatim.
`rs-drive-abci/tests/identity_discovery/mainnet.rs` replays them offline.
